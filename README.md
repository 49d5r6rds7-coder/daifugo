# 大富豪オンライン

友だちとブラウザで遊べる大富豪です。リンクを送るだけで参加でき、ゲームの進行と CPU はサーバー側で動くので、手札は本人の画面にしか送られません。

## ローカルで動かす

```
node server.js
```

http://localhost:3000 を開きます（Node.js 18 以上。外部ライブラリは不要です）。
同じ Wi-Fi の友だちと遊ぶなら、`http://<あなたのPCのIP>:3000` を共有します。

## インターネットに公開する（無料の例：Render）

1. このフォルダを GitHub のリポジトリにアップロードします。
2. https://render.com で「New → Web Service」を選び、そのリポジトリを指定します。
3. 設定は次のとおりです。
   - Runtime: Node
   - Build Command: （空欄）
   - Start Command: `node server.js`
4. 作成すると `https://○○.onrender.com` のURLができます。これがゲームのアドレスです。

Railway、Fly.io、Glitch など、Node.js が動くサービスならどこでも同じように置けます。
無料プランは、しばらくアクセスがないと眠ることがあります。最初の表示に少し時間がかかる場合があります。

## 仕組みと設定

- 部屋はサーバーのメモリ上にあります。再起動すると進行中の部屋は消えます。
- 1手の持ち時間は60秒です。時間切れや、通信が切れたまま戻らない人の手番は自動で進みます。
- 次の環境変数で調整できます：`PORT`、`TURN_MS`（持ち時間）、`DROP_MS`（離席とみなすまで）、`CPU_MS`（CPUの待ち時間）。
- 同時に作れる部屋は500までです。20分間だれも接続していない部屋は自動で片付けます。
